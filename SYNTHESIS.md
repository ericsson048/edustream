## 🔄 État & Flux de Données

```
Initial State
    ↓
API Fetch Discussions + Groups
    ↓
setDiscussions() + setGroups()
setFilteredDiscussions() + setFilteredGroups()
    ↓
Display Content (Loading = false)
    ↓
User Types in Search
    ↓
searchQuery State Updated
    ↓
useEffect Triggers Filtering
    ↓
setFilteredDiscussions() + setFilteredGroups()
    ↓
Component Re-renders with Filtered Results
    ↓
WebSocket Messages Received
    ↓
setDiscussions() or setGroups() Updated
    ↓
Filtered States Auto-Update (useEffect)
    ↓
Display New Content
```
